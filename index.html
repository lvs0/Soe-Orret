SOE-Orret

Block Diffusion Language Model open-source avec sécurité post-quantique

Créé par Lévy Verpoort Scherpereel, 14 ans, France

GitHub Architecture Démo

Problème

Les modèles autoregressifs (GPT, LLaMA) génèrent du texte séquentiellement, token par token. Ils ne peuvent pas réviser ce qu'ils ont écrit, souffrent du "reversal curse", et nécessitent des GPU massifs pour une inférence rapide.

Solution

SOE-Orret utilise la diffusion par blocs : génération parallèle de blocs de tokens, contexte bidirectionnel, révision des tokens peu confiants. Tourne sur un laptop, avec sécurité post-quantique intégrée.

Pourquoi la diffusion ?

↔️

Bidirectionnel

Chaque token voit tous les autres. Résout le "reversal curse".

⚡

Parallèle

K tokens générés par étape. Jusqu'à 10× plus rapide que l'AR.

🔄

Révisable

Les tokens peu confiants sont re-générés. Auto-correction native.

Démarrage rapide

# 1. Installer Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 2. Télécharger le modèle
ollama pull qwen2.5:1.5b

# 3. Cloner et lancer
git clone https://github.com/lvs0/soe-orret
cd soe-orret
python soe/inference.py "Explique la diffusion pour les LLMs en 3 phrases."

Recherche

dLLM State of the Art

Basé sur Fast-dLLM v2 (NeurIPS 2025), qui adapte Qwen2.5-7B en dLLM avec seulement 1B tokens de fine-tuning. Lecture recommandée : LLaDA-8B, MDLM, DiffuLLaMA.

PQC Integration

ML-KEM-1024 (FIPS 203) + ML-DSA-65 (FIPS 204) via Polygone Network. Chiffrement post-quantique de bout en bout pour les agents IA autonomes.
